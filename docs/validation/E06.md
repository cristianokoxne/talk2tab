# E06 — Contrato e avaliação da compreensão do Jev

## Estado: parcial; avaliação real bloqueada

### Contrato confirmado

Referência oficial consultada em 2026-10-09: [System One API reference](https://docs.system-one.dev/en/docs/api). O endpoint documentado é `POST https://system-one.dev/v1/systemone`, autenticado por Bearer, com `model`, `state` e perguntas tipadas. Para `choice`, a resposta usa `answers.<nome>.choice`, com `probabilities` e `confidence` opcionais; a resposta também pode trazer o identificador real do modelo. A documentação orienta copiar o ID exato do catálogo atual de modelos. O adaptador preserva campos opcionais ausentes, rejeita tipo/probabilidades malformados e opções desconhecidas antes de retornar uma ação. O endpoint padrão foi atualizado para o host atual documentado.

O adaptador identifica sua versão como `2`; a decisão preserva `model` quando retornado. Testes sem rede cobrem escolha permitida, ausência de campos opcionais, probabilidades inválidas, opção desconhecida, cancelamento e timeout.
