# E09 — Espera por efeito e recuperação limitada

## Resultado

Cliques e Enter agora aguardam uma mudança de URL/fingerprint semântico por até 3 segundos, usando uma janela curta de estabilidade. A espera observa repetidamente o estado útil da página, então relógios e banners que continuam mudando não a prendem. Observações transitórias têm até duas tentativas adicionais com backoff curto. Erros do Jev só são repetidos para falhas de rede ou HTTP 429/502/503/504, no máximo duas vezes.

Refs obsoletas são recuperáveis somente quando o executor confirma que a ação não foi enviada: a extensão observa novamente e pede uma nova escolha. Se a ação já foi enviada e o resultado não pode ser observado, a sessão termina em `needs_help`, sem repetir o clique/Enter. O mesmo alvo enviado sem efeito observado fica bloqueado até reconciliação.

## Critérios e evidências

- Fixtures com efeitos após 0, 100, 800 e 2.500 ms retornam o mesmo estado final.
- Atualização contínua de banner termina dentro do timeout rígido.
- Falha transitória de observação é recuperada; refs obsoletas geram nova observação/decisão sem redirecionar o clique automaticamente.
- Erro de rede do provider tem retry limitado; ação enviada com observação indisponível e envio sem efeito não são repetidos.
- `npm run typecheck`, `npm run lint`, `npm test` (79 testes), `npm run test:e2e` (12 testes), `npm run bench:replay` e `git diff --check` passaram.

## Limites

A espera compara URL e fingerprint semântico por polling a cada 50 ms, com timeout de 3 s. Eventos de mutação no DOM que não alterem esses sinais não contam como progresso. Recuperação de navegação entre documentos/abas e reconciliação após reinício ficam para E10/E17.
