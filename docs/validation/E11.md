# E11 — Controles contextuais e teclado

## Entrega

- O clique revalida conexão, visibilidade, estado disabled/aria-disabled e bloqueios `inert`/`aria-hidden` imediatamente antes de agir; após rolar, verifica obstrução pelo hit-test central quando o navegador oferece `elementFromPoint`.
- O scanner inclui `summary` e o identifica como botão, mantendo os nomes acessíveis já reconhecidos para controles sem texto (por exemplo, botões com `aria-label`).
- O teclado envia eventos ao elemento realmente focado em raízes Shadow DOM abertas. Enter respeita `preventDefault` e evita o fallback de envio quando um handler já invocou submissão ou o evento `submit` já ocorreu.
- Hover menus e ações que exigem interação confiável do navegador seguem sem simulação ou alegação de sucesso: precisam de suporte específico e verificação de efeito em etapa futura.

## Critérios verificados

- O executor não despacha clique em alvo `aria-disabled`, dentro de região `inert`, ou coberto por outro elemento.
- Enter dispara o envio fallback uma vez; se um handler já pedir envio, não há uma segunda chamada; se o handler cancelar `keydown`, o fallback não envia.
- A suíte continua validando fluxos de diálogo, seleção, navegação e estado observado depois das ações.

## Validação

- `npm run typecheck`: passou.
- `npm run lint`: passou.
- `npm test`: 89/89 testes passaram.
- `npm run test:e2e`: 15/15 testes passaram, incluindo overlay real, fechamento do diálogo com Escape, avanço do foco com Tab e tecla em Shadow DOM aberto.
- `npm run bench:replay`: 120 casos catalogados em 24 famílias.
- `npm run diff-check`: indisponível; não existe script com esse nome no `package.json`.

## Limites conhecidos

- Hit-test é omitido quando `elementFromPoint` não existe (como em alguns ambientes de teste) e verifica o centro do elemento; overlays parciais exigem fixture específica.
- Eventos de teclado sintéticos não equivalem a interação confiável do usuário. O agente só considera concluída uma tarefa após observar o efeito na página.
- Menus acionados exclusivamente por hover ainda são reportados como limitação, em vez de serem tratados como abertos.
