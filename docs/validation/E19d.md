# E19d — Evitar repetir busca sem efeito

Estado: subetapa implementada e validada; E19 **não aprovado**.

Um controle de busca passa a ser considerado tentado assim que o clique é despachado, mesmo se a observação seguinte não encontrar progresso. Isso remove o mesmo botão das opções e permite tentar Enter uma vez. A regressão cobre clique despachado sem progresso; a proteção geral continua impedindo repetição de ações com efeito desconhecido.

Validação: `npm test` (130 aprovados), `npm run typecheck`, `npm run lint`, build e `git diff --check` aprovados. Replay real do conjunto de desenvolvimento: 15/63 (23,81%), sem alteração em relação a E19c; busca 12/42, input 0/9, scroll 3/3 e resultados/navegação/menu 0/3 cada. Relatório: [E19-development-2026-10-10T01-18-35.json](E19-development-2026-10-10T01-18-35.json).

O comportamento repetido continua em alguns sites e a taxa não melhorou. A subetapa não aprova o gate de E19; próximo trabalho deve investigar a identificação do campo/resultado e as decisões reais do Jev usando apenas o conjunto de desenvolvimento.
