Validação: testes específicos de navegação aprovados; `npm test` (133 testes), `npm run typecheck`, `npm run lint`, build e `git diff --check` aprovados. Esta correção não altera a avaliação de sucesso do E19 nem substitui o teste manual de voz no Chrome.
